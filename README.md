# LinkedQueue-Java

A simple implementation of a **Queue using a Doubly Linked List in Java**.

## 📌 About

This project is created to practice and understand the **Queue data structure** and how it can be implemented using linked nodes.

The implementation uses a **circular doubly linked list with a dummy head node**.

## 🚀 Features

* Add elements to the queue
* Get the first element
* Remove elements from the queue
* Check the queue size
* Calculate the sum of integer elements
* Display the queue using `toString()`

## 🧠 Concepts Practiced

* Queue (FIFO)
* Doubly Linked List
* Nodes
* References
* Object-oriented programming
* Methods and classes
* Exception handling
* Sentinel/Dummy node
